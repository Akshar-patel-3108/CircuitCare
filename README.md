# CircuitCare

## Electronics Lab Inventory and Fault Management System

**Course:** Object Oriented Programming (204ES)  
**Language:** C++  
**Project Type:** Individual Project

### Description
CircuitCare is a console-based C++ application designed to manage electronics laboratory equipment, track component stock, and record instrument faults.

### Features
- Add and display components and instruments
- Search equipment by ID
- Update component stock
- Report instrument faults
- Update repair status
- Save records using file handling

### OOP Concepts
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- File handling
- STL containers

### How to Run
Compile `main.cpp` using a C++ compiler that supports C++11 or later, then run the executable.
